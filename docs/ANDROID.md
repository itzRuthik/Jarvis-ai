# Android app & APK

JARVIS AI ships as a **Capacitor 6** Android project that wraps the same web app used in
the browser. There is no separate Android UI to maintain: the HUD, the offline core and
every tool are the exact files in `app/`.

---

## 1. Get the APK in one click

Every push to `main` that changes `app/` or `capacitor/` runs
[`.github/workflows/android.yml`](../.github/workflows/android.yml), which:

1. verifies the app shell (`node tools/verify-shell.mjs`),
2. runs the test suite (`node tools/test.mjs`),
3. installs Capacitor, copies `app/` → `capacitor/www`, syncs the native project,
4. builds with Gradle, and
5. uploads the APK to the workflow **artifact** and to the [latest release](https://github.com/itzRuthik/Jarvis-ai/releases/latest), with `SHA256SUMS.txt`.

You can also trigger it manually: **Actions → Android APK → Run workflow**
(optionally pass a tag such as `v1.1.0` to attach the APK to that release).

---

## 2. Install it on a phone

```bash
# Option A — with a USB cable and the Android platform tools
adb install JARVIS-AI-1.1.0-debug.apk

# Option B — on the device
# 1. Download the .apk from the release page
# 2. Open it; Android asks you to allow installs from this source
# 3. Allow → Install → open “JARVIS AI”
```

The APK is **debug-signed** (Android's standard debug keystore). That is intentional: it
makes the build reproducible and installable without a Play Store account or your own
keystore. Consequence: Play Protect may show a “unknown developer” warning, and the app
cannot be published to the Play Store in this form — a signed AAB track is on the roadmap.

Verify your download:

```bash
sha256sum -c SHA256SUMS.txt
```

## 3. Build it yourself

Requirements: **JDK 17**, the **Android SDK** (platform 34, build-tools 34.0.0), Node 18.17+.

```bash
cd capacitor
npm install

npm run prepare:www        # app/ → capacitor/www  (generated, git-ignored)
npm run sync               # prepare:www + npx cap sync android
npm run build:debug        # gradle assembleDebug
#    → android/app/build/outputs/apk/debug/app-debug.apk

npm run build:release      # gradle bundleRelease
#    → android/app/build/outputs/bundle/release/app-release.aab  (unsigned)
```

Or open the project in Android Studio: `npm run open`.

### What is committed, what is generated

| Path | Committed | Notes |
| --- | --- | --- |
| `capacitor/capacitor.config.json` | ✅ | app id, webDir, splash, status bar |
| `capacitor/android/**` (sources, Gradle files, wrapper, resources) | ✅ | the real native project |
| `capacitor/www/**` | ❌ | generated copy of `app/` — never edit by hand |
| `capacitor/android/app/src/main/assets/public/**` | ❌ | generated by `cap sync` |
| `capacitor/android/app/build/**`, `.gradle/**` | ❌ | build output |

**Never edit files under `capacitor/www` or `assets/public`** — they are overwritten by
`npm run sync`. Change `app/` instead (or the flow is: edit `app/` → `npm run sync`).

## 4. App identity

| Property | Value |
| --- | --- |
| Application ID | `com.itzruthik.jarvisai` |
| Display name | JARVIS AI |
| Version name / code | `1.1.0` / `3` (in `capacitor/android/app/build.gradle`) |
| min / target SDK | 22 / 34 |
| Launcher icons | `res/mipmap-*/ic_launcher.png`, `ic_launcher_round.png`, adaptive foreground + `#03070F` background |
| Splash screens | `res/drawable*/splash.png` — deep navy with the reactor emblem |
| Status bar / navigation | dark, overlaying, themed `#03070f` |

To regenerate icons after changing the artwork, rerun the same ImageMagick pipeline the
repository used:

```bash
SRC=path/to/icon-source.png
for pair in "mdpi 48" "hdpi 72" "xhdpi 96" "xxhdpi 144" "xxxhdpi 192"; do set -- $pair
  convert "$SRC" -resize ${2}x${2} -strip capacitor/android/app/src/main/res/mipmap-$1/ic_launcher.png
done
```

## 5. Permissions

Declared in `capacitor/android/app/src/main/AndroidManifest.xml`:

| Permission | Why |
| --- | --- |
| `INTERNET` | Talking to the AI providers and search services you configure |
| `RECORD_AUDIO` | Voice input through the Web Speech API |
| `MODIFY_AUDIO_SETTINGS` | Routing for speech capture/playback |

`usesCleartextTraffic="false"` is set, so the app only talks HTTPS. The app declares no
location, contacts, storage or telephony permissions and contains no analytics SDKs,
because it contains no SDKs at all beyond Capacitor itself.

## 6. Platform behaviour and honest limitations

| Capability | In the Android app | Notes |
| --- | --- | --- |
| Offline core, tools, notes, tasks, memory | ✅ full | Local storage inside the WebView |
| Streaming AI conversation | ✅ full | HTTPS to the provider or your proxy |
| Spoken replies (TTS) | ✅ works | Android system speech synthesis |
| Speech recognition (STT) | ⚠️ depends on the device | Android WebView supports the Web Speech API only when the Google speech service is present. If it does not respond, use **voice typing on the keyboard** (Gboard's microphone) — the input field supports it. |
| Wake word | ⚠️ requires an active recognition session | True always-on wake word needs a background service; that is on the roadmap. Keep the screen on with wake word armed for now. |
| PWA install prompt | n/a | The APK *is* the install |
| Service worker | ✅ registered | Caches the shell inside the WebView |
| Notifications | ➖ not used | No notification permissions requested |

If your device's WebView lacks STT and you want first-class native recognition, the clean
path is a Capacitor speech plugin — it is listed in the roadmap as a planned enhancement,
kept out of the default build so the app stays dependency-free.

## 7. Troubleshooting

| Symptom | Fix |
| --- | --- |
| `SDK location not found` | Install the Android SDK and set `ANDROID_HOME`, or add `sdk.dir=` to `capacitor/android/local.properties`. |
| `Unsupported class file major version` | Use JDK 17 (not 11, not 21+). |
| Blank screen after launch | Run `npm run sync` — the web assets must be copied before building. |
| Gradle download stalls | First build downloads the Gradle distribution; run it once with a good connection. |
| App opens to a file-not-found page | Check `webDir` in `capacitor/capacitor.config.json` is `www` and that `prepare-www.mjs` ran. |
| Voice button does nothing | Device WebView lacks STT — see the limitations table above. |
