# Code of Conduct

## Our pledge

We want JARVIS AI to be a place where anyone can learn, build and ask questions without
being made to feel unwelcome. Everyone participating — issues, pull requests, discussions —
is expected to help keep it that way, regardless of experience level, background, identity
or how trivial a question might seem.

## Expected behaviour

- **Be kind and specific.** Critique the code, not the person.
- **Assume good faith.** Most disagreements are about missing context.
- **Be honest about limitations.** This project documents what does not work; please do the same in issues and PRs.
- **Credit others.** Link the source of an idea, snippet or design inspiration.
- **Respect the boundary between inspiration and infringement.** JARVIS AI is an original,
  fan-made project. Do not push changes that copy protected artwork, logos, scripts or
  dialogue, or that imply endorsement by any rights holder.

## Unacceptable behaviour

- Harassment, insults, or discriminatory comments of any kind.
- Sexualised language or imagery, and unwelcome attention.
- Publishing someone's private information without permission.
- Trolling, deliberate derailing, or repeated bad-faith arguing.
- Encouraging or facilitating the misuse of the project (for example, helping someone
  commit fraud, or ship stolen credentials through the app).

## Scope

This applies to all project spaces — the repository, issues, pull requests, release
discussions — and to any situation where someone is representing the project publicly.

## Enforcement

Report unacceptable behaviour to the maintainer via their GitHub profile (or a private
security advisory if you prefer). Reports are handled confidentially. Responses scale with
the behaviour and may range from a private warning, through removing comments, to a
temporary or permanent ban from the project.

## Attribution

This Code of Conduct is a shortened, project-specific adaptation of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1. Where the two
differ, this document governs for this project.
